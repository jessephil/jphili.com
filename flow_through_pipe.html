Hagen-Poiseuille & Related Equations

Q = π d⁴ ΔP / (128 µ L) Re = ρ V d / µ   (Re < 2,300 → laminar) P = Q · ΔP   [hydraulic power] ν (cSt) = 10^(10^(A − B·log(T_K)) − 0.7)   [Walther equation for ISO oils] µ (cP) = ν · ρ / 1000   (ρ ≈ 850 kg/m³ assumed for ISO oils)
Q = volumetric flow rate d = pipe inner diameter ΔP = pressure drop µ = dynamic viscosity L = pipe length ν = kinematic viscosity (cSt) T_K = temperature in Kelvin A, B = Walther coefficients fitted to 40°C & 100°C viscosity
