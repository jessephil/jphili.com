Power Screw Equations (Shigley / Machinery's Handbook)

Raising: T_r = F·dm/2 · (l + π·µ'·dm) / (π·dm − µ'·l) Lowering: T_l = F·dm/2 · (π·µ'·dm − l) / (π·dm + µ'·l) µ' = µ / cos(α)   [modified friction for V/ACME thread] dm = D − p/2   [mean thread diameter] l = starts × p   [lead] λ = arctan(l / π·dm)   [lead angle] φ = arctan(µ')   [friction angle] Self-locking: λ < φ   (i.e. µ > tan λ · cos α) η = F·l / (2π·T_r)   [raising efficiency] Back-drive torque = T_l (positive = requires torque to lower; negative = self-locking)
α = thread half-angle (0° square, 14.5° ACME, 30° V-thread) dm = mean thread diameter l = lead (= pitch × starts) µ' = modified friction coefficient λ = lead angle φ = friction angle
