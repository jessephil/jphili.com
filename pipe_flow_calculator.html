Governing equations

Laminar (Re < 2,300): Q = π·d⁴·ΔP / (128·µ·L)   [Hagen-Poiseuille] Turbulent: ΔP = f·(L/d)·(ρV²/2)   [Darcy-Weisbach] Colebrook-White: 1/√f = −2·log(ε/(3.7d) + 2.51/(Re·√f))   [iterated] Swamee-Jain (explicit): f ≈ 0.25 / [log(ε/(3.7d) + 5.74/Re⁰·⁹)]² Re = ρ·V·d / µ   |   V = Q / A   |   P = Q·ΔP
ε = absolute pipe roughness ε/d = relative roughness f = Darcy friction factor (4× Fanning) Transitional 2,300 < Re < 4,000 — neither equation is reliable For ΔP→Q turbulent: iterative solution using Colebrook-White
