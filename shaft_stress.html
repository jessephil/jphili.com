Torsional Shear Stress — Solid & Hollow Shafts

Solid shaft: τ = 16T / (π·d³) Hollow shaft: τ = T·(D/2) / J   where J = π(D⁴ − d⁴) / 32 k'w = 1 + 1.5·(b/d) + (h/d)   [AGMA keyway SCF] τ_allow = YS / (2 · SF)   [von Mises shear yield] T_max = τ_allow · J / c   [max torque from allowable stress]
T = applied torque (in·lb) d = solid shaft diameter D / d = hollow OD / ID J = polar moment of inertia c = outer radius b = keyway width h = keyway depth SF = safety factor YS = material yield strength
